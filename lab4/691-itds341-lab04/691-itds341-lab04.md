## Task 4: Detect Potential Outliers Using Z-score

Use the following rule for this exercise:

```text
Potential Outlier: |Z-score| ≥ 3
```

For each score column:

1. Calculate its Mean and Standard Deviation.
2. Calculate the Z-score of every observation.
3. Identify observations with an absolute Z-score greater than or equal to 3.
4. Display all records flagged in at least one score column.

You may begin with:

```python
z_scores = (
    score_df[score_columns] - score_df[score_columns].mean()
) / score_df[score_columns].std()

zscore_flag = z_scores.abs() >= 3
```

Create a Boolean mask that identifies records flagged in at least one column:


## Task 5: Detect Potential Outliers Using IQR

For each score column:

1. Calculate `Q1` and `Q3`.
2. Calculate `IQR = Q3 - Q1`.
3. Calculate the Lower and Upper Fences.
4. Identify observations outside the Fences.
5. Display records flagged in at least one score column.

The formulas are:

```text
Lower Fence = Q1 − 1.5 × IQR
Upper Fence = Q3 + 1.5 × IQR
```

You may begin with:

```python
q1 = score_df[score_columns].quantile(0.25)
q3 = score_df[score_columns].quantile(0.75)
iqr = q3 - q1

lower_fence = q1 - 1.5 * iqr
upper_fence = q3 + 1.5 * iqr

iqr_flag = (
    (score_df[score_columns] < lower_fence) |
    (score_df[score_columns] > upper_fence)
)

iqr_row_flag = iqr_flag.any(axis=1)
iqr_outliers = score_df.loc[iqr_row_flag]

display(iqr_outliers)
```

Display the calculated Fences:

```python
fences = pd.DataFrame({
    "Lower Fence": lower_fence,
    "Upper Fence": upper_fence
})

display(fences)
```

## Task 6: Detect Multivariate Outliers Using Isolation Forest

Z-score and IQR examine each score column separately. Isolation Forest considers the combination of several score variables.

Create and train the model:

```python
from sklearn.ensemble import IsolationForest

model = IsolationForest(
    n_estimators=100,
    contamination="auto",
    random_state=42
)

labels = model.fit_predict(
    score_df[score_columns]
)

scores = model.decision_function(
    score_df[score_columns]
)
```

Add the results to a new DataFrame. Do not overwrite the original `score_df`.

```python
isolation_result = score_df.assign(
    anomaly_score=scores,
    potential_outlier=(labels == -1)
).sort_values("anomaly_score")

display(isolation_result)
```

Display only records classified as Potential Outliers:

```python
display(
    isolation_result[
        isolation_result["potential_outlier"]
    ]
)
```

### Interpretation

- `labels == 1` indicates an Inlier.
- `labels == -1` indicates a Potential Outlier.
- A lower `anomaly_score` indicates that the observation appears more unusual relative to the other records.
- `contamination="auto"` allows the model to set its decision threshold automatically. It does not mean that the model knows the true number of errors.

### Questions
